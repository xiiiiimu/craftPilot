## 问题与修订前后差异

### R0-01 P0 调查截止与证据水位

- 位置与原设计。PRD §6、状态机 调查与业务授权。写了半开窗口和水位，但未统一迟到推进、开新调查与异步投影写入的锁和时间。
- 可复现风险。关闭定时器停滞时出现迟到证据、排队任务越窗或同群开新失败。
- 修订后。统一 Group→Survey、锁后数据库时钟、有效状态即时裁决、水位事务、收尾白名单与原文覆盖缺口。
- 联动文件。架构、契约、数据、评测、历史计划。
- 验证与状态。T01/T13。设计已修。

### R0-02 P0 审批决定、恢复与消费

- 位置与原设计。状态机 Approval/Checkpoint、契约 ApprovalService。批准绑定暂停头，未定义恢复推进后如何消费，也未定义批准后到期。
- 可复现风险。批准后卡在旧头或并发关闭后仍发布记忆。
- 修订后。续跑命令幂等、绑定同一操作链、决定/应用/消费各验有效 ACTIVE，写入与消费同库事务。
- 联动文件。PRD、数据、安全、评测。
- 验证与状态。T02/T04。设计已修。

### R0-03 P0 执行原子性及租约

- 位置与原设计。状态机 Run/工具、数据 agent_turn/checkpoint。响应、意图、头和收据分别描述，租约缺少 owner/续租与并行合并规则。
- 可复现风险。提交回包丢失后重做调用，旧 Worker 写入或并行结果覆盖。
- 修订后。定义单 Run 协调租约、epoch、原子 Turn 提交、transition key、账本和未决效果分类。
- 联动文件。架构、契约、数据、安全、评测。
- 验证与状态。T03/T04/T05。设计已修。

### R0-04 P0 租户与调查范围隔离

- 位置与原设计。数据模型 表关系、安全 信任边界。仅概述复合外键和 tenant 过滤，缺少调查样品白名单、重放及恢复重鉴权。
- 可复现风险。同租户跨调查引用、撤销后重放命令、复用旧证据或越权附件。
- 修订后。补充复合目标键、白名单、出站及缓存重检、当前成员和历史证据显式授权。
- 联动文件。PRD、契约、架构、评测。
- 验证与状态。T06/T08/T11。设计已修。

### R0-05 P0 Outbox 与对象一致性

- 位置与原设计。数据模型 事务与物理存储、PRD §8。仅说明跳锁领取及暂存清理，消费收据、ack 与对象删除竞争未闭合。
- 可复现风险。丢 ack 重做业务效果或清理已发布的对象。
- 修订后。业务事务内收据、claim/ack 条件更新、DLQ 保留 eventId，MinIO 状态 CAS 及 DB 权威。
- 联动文件。契约、安全、评测、路线图。
- 验证与状态。T10。设计已修。

### R0-06 P1 Assignment

- 位置与原设计。PRD §4、架构 控制面、数据 Ticket/Attempt。Assignment 仅出现在上游研究。
- 可复现风险。无法区分业务分派、执行重试和 Worker 换手。
- 修订后。持久化 Assignment，定义一对一 Attempt、活跃唯一、分配接口及退出传播。
- 联动文件。状态机、契约、数据、路线图。
- 验证与状态。T03/T13。设计已修。

### R0-07 P1 Supervisor、Handoff 与 Join

- 位置与原设计。架构 调度、契约 AgentDelegator。spawn/join 有基本描述，Supervisor/Handoff 缺少角色决策及持久身份。
- 可复现风险。重复委派、部分失败与预算继承无法验收。
- 修订后。Supervisor 受控计划、Handoff key、范围交集、固定 Join、失败策略。
- 联动文件。数据、状态机、安全、评测、路线图。
- 验证与状态。T05。设计已修。

### R0-08 P1 Skill Snapshot

- 位置与原设计。契约 SkillRegistry、数据 skill_release。只有发布版本解析，无 Run 物化快照。
- 可复现风险。升级或恢复可能取到不同指令或已撤销工具。
- 修订后。保存 Skill Snapshot、固定清单/hash/角色/schema、动态撤销重检。
- 联动文件。PRD、架构、数据、安全、评测、路线图。
- 验证与状态。T06。设计已修。

### R0-09 P1 MCP 协议契约

- 位置与原设计。契约 工具清单与 MCP、安全 MCP 工具调包。只写目标版本与 tools/list/call，缺 HTTP 帧、认证及失败约定。
- 可复现风险。实际客户端用错旧式会话、SSE 或无法处理 MRTR。
- 修订后。对照 2026-07-28 规范补线契约、独立凭证、失败分类和真实报文准入。
- 联动文件。架构、安全、评测、路线图。
- 验证与状态。T07。设计已修，线协议待联调。

### R0-10 P1 混合检索与引用

- 位置与原设计。契约 Retrieval/Evidence、数据 evidence_chunk。仅向量搜索和引用 ID 校验。
- 可复现风险。材料编号召回差，跨版本误命中，引用存在但事实不成立。
- 修订后。统一过滤后词法与向量融合、RRF、可解释降级、证据绑定与事实核验。
- 联动文件。PRD、架构、数据、评测、路线图。
- 验证与状态。T08/T12。设计已修，质量待验证。

### R0-11 P1 Context 与 Memory

- 位置与原设计。架构 Context、契约 Memory、数据 memory_proposal。压缩和撤销语义不完整，提案可能依赖尚未提交的报告。
- 可复现风险。恢复重用撤销信息或无法执行首次提案。
- 修订后。保留工具消息配对与来源映射，提案引用已持久证据，撤销和生命周期重验。
- 联动文件。数据、安全、评测。
- 验证与状态。T09。设计已修。

### R0-12 P1 旧集成残留

- 可复现风险。按旧字段建表或误走 DeerFlow 部署与接口。
- 修订后。替换为内部 Assignment/Attempt/Run 关系，统一窗口和索引基线，历史方案明确废弃。
- 联动文件。现行数据、架构、三份历史文档。

- 可复现风险。前置工作等供应商或迁移先猜字段。

## 冻结边界与仍需证据

- 反馈截止是新动作的授权边界。收尾属于已启动任务，独立于审批有效期。提前关闭只缩短反馈期限。历史报告确认不产生运行授权。
- 每 Run 单一持租约协调者，有界并发执行子任务。跨进程可靠性由 PostgreSQL 状态、epoch、Outbox 和账本提供。没有新增中间件。
- 当远端请求可能已经到达，状态查询优先；只读且仍在授权和预算内可重试，未知外部写仅对账或人工处理。应用数据库内效果唯一约束与全链路至少一次分开验收。
- MCP 版本的官方规范已对照；实际报文、认证、模型能力、视觉与向量请求、费用及性能均待真实验证。此前面经原题未在当前项目定位，尚未逐题核对。
