# CraftPilot R0 技术风险登记

以下为修订后剩余的实施风险。设计控制已定义，验证均待执行。失败影响对应阶段准入或退出。

| 风险 | 触发与影响 | 控制与验证 | 责任阶段 |
|---|---|---|---|
| K01 截止漂移 | 定时器滞后、锁等待越期、人工与自然关闭竞态 | DB 时间、半开窗口、时间生效先于物化；T01/T02 | R1/R4 |
| K02 恢复重复效果 | 旧 epoch 回包、请求或 ack 丢失 | 持久账本、CAS、单 Run 租约、唯一效果收据；T03/T04/T10 | R1/R3 |
| K03 授权与缓存泄漏 | 跨商家 FK、撤销后缓存命中、历史证据或对象链接 | DB 授权重检、范围外键、下载代理；T08/T11 | R1/R2/R4 |
| K04 远端不确定 | 已发送请求超时、取消后继续计费、结果不可查 | 限次只读重试、未知预算、隔离迟到结果；未知写仅人工；T03/T12 | R3/R5 |
| K05 连接器漂移和 SSRF | 库默认旧协议、Schema 或目标变化、重绑定 | 固定协议和目标、禁止自动降级、验实际连接 IP；T07 | R4 |
| K06 反馈与检索质量 | 中文词法、版本混淆、票数与主张误配、图像误推断 | 范围内词法与向量、标注集、结构化事实核验；T08/T12/T13 | R2/R5 |
| K07 并行争用 | 多 Run 占满 DB/HTTP 池、租约过期、Join 慢任务 | 有界并发、独立心跳和预算、确定性 Join；T04/T05，负载记录 p95 | R3/R4 |
| K08 对象与事件积压 | Redis 清空、MinIO 写/删失败、Outbox DLQ 积压 | DB 权威、对象版本/CAS、稳定重放及告警；T10 | R1/R5 |
| K09 注入与记忆污染 | 不可信文本要求越权、过期摘要重用 | Broker 独立校验、显式记忆审批及来源失效；T06/T09/T11 | R3/R4 |
| K10 证据覆盖不齐 | 反馈或外部读取在收尾才返回 | 冻结范围、晚到不纳入、报告披露缺口；T01/T12 | R2/R5 |

无需增加消息中间件、独立向量库、工作流引擎或新的业务数据库。复核成本集中在 DB 锁竞争、IO 并发和真实模型用量。
