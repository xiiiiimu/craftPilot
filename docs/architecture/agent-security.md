# CraftPilot Agent 权限与安全

## 信任边界

商家、群管理员和群成员通过业务认证进入。业务控制面根据实际身份读取角色和成员关系。Runtime、Worker、MCP 客户端及模型各自只取得任务所需的最小数据。数据库只向业务进程开放。运行授权包含 merchant、group、survey、ticket、run、task、允许的 revision、工具与效果类别、期限和租约 epoch，子 Agent 从父范围取交集。

| 攻击或竞态 | 控制与失败行为 |
|---|---|
| 猜测跨租户 ID | 所有读、写、事件流、证据向量查询、缓存键及 MinIO 下载授权绑定商家。复合外键与授权查询共同防护。HTTP 返回 404 或已授权对象的 403。 |
| Prompt 注入 | 群消息、图片 OCR、MCP 响应、RAG 及记忆作为非可信数据，模型无法改变工具清单、审批、作用域和目标连接。Tool broker 独立校验 schema 与权限，输出再次净化。 |
| 调查与审批过期 | 锁内读取数据库时钟，截止等号即失效。关闭事务撤销订阅、未消费批准及未启动运行。继续写入必须消费绑定操作的审批；迟到批准、迟到恢复和旧 Worker 提交全部拒绝。 |
| Checkpoint 篡改与重放 | 不可变头、作用域、版本、内容摘要和当前 lease epoch 一起核验。恢复不载入已撤销证据、停用工具或旧审批。 |
| 重复工具及副作用 | 逻辑调用键、参数摘要、物理尝试账本和业务唯一收据。批准绑定具体操作；改参需重新批准。未知外部写禁止自动重试。 |
| SSRF 与执行逃逸 | 工具仅能用预注册实现，禁任意 shell、任意 URL、动态插件和数据库自由查询。允许的出站域、端口、解析地址和重定向逐跳校验，拦截私网及元数据地址；私有连接器由部署管理员显式登记且固定目标。HTTP 出站受超时、请求大小及响应大小约束。 |
| MCP 工具调包 | 固定连接器身份、协议和工具 schema 摘要。目录变更需重新审批发布。MCP 注解不用于授予本地权限，返回内容不可注册新工具。 |
| 凭证及附件外泄 | API 密钥由部署注入；日志、模型上下文、Checkpoint、错误和事件脱敏。私有图片短期访问按目的和范围核验，撤销敏感文件时优先经应用代理实现即时授权判定。已交付给第三方的输入依供应商留存策略治理。 |
| 资源耗尽 | 按调查和租户预留预算与并发配额，子 Agent 共用总预算。限制上下文、图步数、工具次数、返回大小、时长与递归深度。超限取消新动作并留下用量及证据缺口。 |

安全审计记录 actor、scope、动作、批准 ID、工具版本、请求摘要、证据、判定和 trace。群管理员可操作被授权调查，商家负责受限写入审批及最终建议确认。运维通过脱敏日志和指标排障。紧急禁用租户、成员、连接器、工具或证据后，所有准入、派发、恢复、幂等结果重放和报告发布均重新校验。远程源码的边界借鉴及实际文件见 [架构](runtime-architecture.md#远程源码依据)。

## 执行与数据出站

- 模型仅能提出工具或 Handoff 请求。Broker 从数据库重新派生权限，校验 task 属于 run、run 属于 ticket、样品属于授权清单，校验参数、体积、预算、版本和 epoch。应用级工具隔离依靠固定 Java 处理器及受控 HTTP 客户端；禁用任意脚本、动态 MCP 发现地址及运行时插件。
- MCP 配置按商家、环境和目的隔离。DNS 解析到实际连接 IP 再按 allowlist 检查，HTTPS 校验证书和主机名；默认禁止重定向，受控私有目标通过独立静态配置登记。元数据地址和环回不接受商家输入。审计仅存端点标识、请求摘要、trace 与返回分类。
- 向量、词法、候选缓存及摘要以相同可见性边界过滤。缓存命中也重验授权；撤销来源使上下文摘要与关联记忆失效。公开报告和事件不返回可绕过应用鉴权的对象 URL。群成员撤销后关闭其 WS 订阅，补读也重新鉴权。
- 效果收据为当前数据库内的一次性约束。外部只读访问可能重复，模型可能计费；全链路不承诺 exactly-once。当前工具不包含外部写；扩展前必须证明远端授权、幂等及对账能力。
