# CraftPilot Agent 评测与验收

## 评测方式

固定数据集、标注、Workflow、Skill、工具 schema、模型配置和评测器版本。回放集包含 3 商家、6 群、12 调查、约 1200 消息、约 300 有效观点、至少 20 款式、30–50 张样品图，覆盖娃衣、饰品和 V1/V2。使用带真实来源关系的去标识化或明确标注的演示数据，标注集与阈值调参集分开。

- 确定性回放用于编排和故障注入，可使用已录制模型响应。报告标记运行模式与记录来源。
- 集成测试启动真实 PostgreSQL、Redis、MinIO、业务工具及 MCP HTTP 服务。使用并发屏障、不同 Worker 和实际事务验证竞争，在纯判定测试注入相同时间验证等号，在数据库集成测试通过屏障跨过真实截止。
- 端到端发布验收使用真实推理模型、OpenAI Embedding、Qwen-VL、真实材料资料 MCP 查询。保留脱敏请求、工具执行收据和实际使用量。回放和假响应只计入对应测试，不计入真实调用通过数。

## 能力验收矩阵

| 能力 | 场景与通过条件 |
|---|---|
| 商品、群聊、调查及 Trigger | V1/V2 历史可读；同键重复消息零重复；并发开调查仅一条成功；同批触发只建一个 Ticket；关闭后消息仍显示且旧 Ticket 唤醒为零。 |
| 模型适配和 Tool Calling | 模型先请求读取样品，依据真实结果再请求反馈或视觉工具，输出引用；畸形增量、schema 错误和截断均不派发；401、429、超时分别进入规定路径。 |
| Workflow | 条件节点依据样品与反馈证据选择执行路径；重复完成事件不重复转移；证据检查失败不发布报告。 |
| Multi-Agent | 视觉和反馈任务真实并行执行，汇合得到可溯源结果；子范围不能越权，超预算或取消时后代停止，超时部分结果明示。 |
| Skills | 按发布版本激活 launch-research；被停用版本在恢复时失败关闭；运行中上线新版本不改变原 Run。 |
| MCP | 实际 tools/list 与 tools/call 读取资料并产生 B 级证据；非法域、工具漂移、越权、超时及 schema 不符拒绝。 |
| RAG | 交叉构造相似的 V1/V2 和跨租户观点，检索只返回授权版本；每个片段可追溯原文，撤销后检索和恢复均不可见。 |
| Memory | 提案、审批、写入、后续调查同商家读取、撤回逐步验证；其他租户、未经批准或过期内容无法读取。 |
| Context | 证据超限时优先保留必要来源及不确定性，裁剪后仍能定位引用；注入文本不能改变工具许可。 |
| Checkpoint 和恢复 | 分别在模型返回、工具意图写入、派发、业务效果提交及 head 推进处杀 Worker。恢复沿当前头继续，成功效果零重放；旧头、重复恢复命令和旧 epoch 拒绝。 |
| HITL | 通过及拒绝均能审计；批准后掉线、批准和关闭竞争、批准后实际执行前过期、同时批准两次均最多一次效果且越期零写。 |
| 取消和到期 | 同时取消及恢复、跨 Worker 取消、收尾定时器停滞、晚到模型结果均测试；到期无新运行/审批执行，晚到结果不改变终态。 |
| 重复调用和未知效果 | 同调用重试复用回执；同键异参数拒绝；丢回包恢复只读或查询；不明外部写零自动重复。 |
| 权限和安全 | 群/租户隔离、恶意工具参数、越权附件、日志脱敏、SSRF 和 MCP 注入；证据、事件、缓存、文件四处均验证零泄漏。 |
| 可观测性和评测 | 从消息、触发、Ticket、Attempt 追到工具/模型耗时、用量、审批和报告；真实评测输出数据集、版本、实际结果、证据与失败归因。 |

发布硬门槛为上述安全、时间和一致性用例全过，测试集明确卡片归因和消息幂等 100%，跨租户泄漏、截止后副作用、重复业务效果和旧 Ticket 唤醒为零。PRD 质量目标为模糊归因 ≥85%、Issue macro-F1 ≥0.80，需标注样本、分母和混淆矩阵。补充记录 RAG Recall@K、引用有效率、每项主张有证据比例、工具成功率、p95 延迟、取消确认时延、每轮调用成本。每条正式报告的事实引用须可校验，推断逐条标示，缺失事实写未知。月度 ¥300 仍为预算目标。

## R0 补充验收用例

所有用例当前为待执行。使用 PostgreSQL 16 双连接/双 Worker、事务屏障、短期限测试配置与真实 `clock_timestamp()`。固定种子和数据集，分别报告功能、故障、性能与真实协议结果。

| ID | 自动化输入与判定 |
|---|---|
| T01 | 构造窗口前、等于、晚于截止并阻塞定时器；等待锁越过截止的消息只进群聊；开新调查推进旧状态；关闭前允许的投票及证据水位可复查。 |
| T02 | 审批决定后延迟消费至截止，或与提前关闭、重复审批并发。只接受锁内有效操作，效果收据至多一条；拒绝路径不写记忆。CLOSED 后同报告可独立确认。 |
| T03 | 在模型前后、完整帧提交、工具意图、DISPATCHING、效果提交及 Checkpoint 更新逐点终止 Worker；对已提交步骤不重复逻辑执行，未决远端效果进入对账。 |
| T04 | 暂停后发两次恢复，再与取消和旧 Worker 回包交叉。只有有效 epoch 推进头；重复响应返回原命令，旧头失败，未知费用可追踪。 |
| T05 | Supervisor 委派视觉和反馈并行，重复交接、一个超时、一个成功及父取消。Join 固定成员且无重复子任务，权限和预算不超父范围。 |
| T06 | 两个 Skill 版本、运行中发布新版和撤销旧版，恢复使用固定快照或失败关闭。注入指令、变更 Tool Schema 或发未知工具时零出站。 |
| T07 | MCP 真实 POST tools/list 与 tools/call，分别验证 JSON/SSE、认证拒绝、目录漂移、header/body 不一致、schema 异常、超时、MRTR 或明确拒绝、DNS 重绑定拦截。脱敏保存线报文及实际工具收据。 |
| T08 | 用材料编号、同义文本及跨版本诱饵测试两路召回、RRF 稳定顺序、范围过滤、撤销源和降级。验证结构化事实与来源一致，伪造引用拒绝。 |
| T09 | 压缩含多轮工具消息及撤销源的 Context；保持调用结果配对与可定位引用。记忆审批、读取、生命周期、撤回及恢复重验。 |
| T10 | 并发领取 Outbox、消费者写入后丢 ack、租约过期、DLQ 重放、Redis 清空、MinIO 暂存竞态及缺失对象。验证零重复业务效果、只广播已提交消息、Redis 可恢复且授权正常。 |
| T11 | 直接尝试跨商家、跨群和调查 FK 写入；测 API、WS、缓存、MCP、附件、幂等重放及撤销后恢复。预期零未授权响应或持久效果。 |
| T12 | 真实模型完整多轮工具调用，OpenAI Embedding 和 Qwen-VL 真实请求，报告附图、反馈、工具执行收据。关联 trace、预算预留、真实用量和未知用量；计算成本与 p95，记录样本量和环境。 |
| T13 | 商家创建企划和 V1/V2、发卡片、回复、投票及购买意愿、人工归因修正、聚合、触发 Ticket 和 Assignment、确认报告。复现已结束调查不可被新消息唤醒。 |

指标口径至少包含分母、数据集版本和运行模式。引用有效率按可见且 hash/区间校验通过的引用除以全部引用。事实支持率按已核对支持的事实除以全部事实。Recall@K 仅用标注候选。取消确认分别记录本地授权失效和供应商确认耗时。成本区分确认、估算及未知，禁止以估算替代账单。

运行指标使用 Spring 可观测性接口接出，不引入新平台。计数器覆盖模型/工具成功、超时、拒绝、预算及死信；分布统计模型和工具延迟、队列等待、租约换手及本地取消耗时。标签限阶段、供应商、结果分类等低基数值。租户和调用标识仅写受控 trace 与数据库账本。
